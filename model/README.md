# Simulation Model

This folder contains the AnyLogic implementation of the MRI department simulation.

## Model File

```text
FinalLogicT3.alp
```

The model represents the MRI examination and reporting workflows developed for the project.

The simulation includes processes such as:

* Patient registration
* EHR checking
* Insurance and copayment
* Patient preparation
* Consultation
* MRI availability and waiting
* Contrast-agent administration
* MRI examination
* MRI room selection
* IV removal
* Patient discharge
* MRI reporting

The model also includes an optimization experiment focused on the employment percentage of personnel involved in the MRI department.

## Simulation Horizon

The simulation model was run for a simulated duration of **90 hours** for system performance analysis.

## Software

**AnyLogic**

To inspect or execute the model, open:

```text
FinalLogicT3.alp
```

using AnyLogic.
